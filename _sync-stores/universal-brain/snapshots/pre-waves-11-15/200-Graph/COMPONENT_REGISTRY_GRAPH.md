## Wave 2 expansion plan

For each of the 63 components, Wave 2 will:

1. Read `OVERVIEW.md` → extract `description`, `category`, `deprecated` field
2. Read `API.md` → extract Variants, Sizes, States → emit `HAS_VARIANT` / `HAS_SIZE` / `HAS_STATE` edges
3. Read `TOKENS.md` → extract DesignTokens + CSSVariables → emit `DEFINES_TOKEN` / `DEFINES_CSS_VARIABLE` / `USES_CSS_VARIABLE` edges
4. Detect wrapper-vs-stencil by file/component prefix → classify as `WrapperComponent` or `StencilComponent` → emit `WRAPS` edges between paired components
5. Read `INTEGRATION_VALIDATION.md` → extract `HAS_VALIDATION` edges to `ValidationRule` nodes (xlsx-confirmed only)
6. Read `GAPS_AND_UPGRADES.md` → emit `HAS_GAP` edges to `Gap` nodes
