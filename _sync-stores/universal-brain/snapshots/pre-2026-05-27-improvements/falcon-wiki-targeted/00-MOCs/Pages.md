# Pages

## All pages (sorted by UX parity)

```dataview
TABLE WITHOUT ID
  file.link as "Page",
  status as "Status",
  ux-parity as "UX %",
  length(components) as "Components",
  length(gaps) as "Open gaps"
FROM "20-Pages"
WHERE type = "page"
SORT ux-parity ASC, file.name ASC
```

## Pages with open gaps

```dataview
TABLE WITHOUT ID
  file.link as "Page",
  length(gaps) as "Gaps",
  ux-parity as "UX %"
FROM "20-Pages"
WHERE type = "page" AND length(gaps) > 0
SORT length(gaps) DESC
```

## Pages awaiting verification (>90 days)

```dataview
TABLE WITHOUT ID
  file.link as "Page",
  verified-at as "Last verified",
  verified-by as "By"
FROM "20-Pages"
WHERE type = "page" AND (date(today) - date(verified-at)).days > 90
SORT verified-at ASC
```

## How to add a page

In any folder, run **Templater: new-page** (or copy `_templates/new-page.md`). Fill in frontmatter relations and TL;DR. Save as `20-Pages/<Page-Name-Kebab>.md`.
