# Falcon Knowledge Graph Vault (Projection over Brain Outputs)

**Status:** 🟢 ACTIVE (2026-05-14, pivoted same-day)
**Location:** `C:\Falcon\falcon-wiki`
**Source of truth:** `C:\Falcon\Brain Outputs\` (NOT the vault)

## What it is
The vault is a **thin projection / navigation layer** over Brain Outputs — NOT a parallel knowledge store. Brain Outputs is where facts live. Brain SK skills are the only writers. The vault is regenerated from Brain Outputs by `scan-brain-outputs.ps1`. Every projection note transcludes canonical content via `![[_mounts/brain-outputs/...]]`. The vault adds frontmatter so Dataview can query relations, plus a graph view for navigation, plus the AI-Agent-Onboarding contract.

## Why this pivot (initial vault was wrong)
The first pass duplicated content Brain Outputs already had (60 component dossiers, per-page dossiers with 14 files each, frontend understanding masters). Hand-authored vault notes would drift from Brain SK skill regeneration within a week. Correct shape: Brain Outputs = SoT, vault = index.

## Source-of-truth tier order (canonical, from Brain SK)
1. Architecture Wiki (`_mounts/brain-outputs/wiki-architect/` + `falcon-wiki/Home/Software-Architecture-Design/`)
2. Backend / API truth (`_mounts/services/<svc>/` controllers, DTOs, validators)
3. PRD (`_mounts/brain-outputs/prd/modules/` and `10-PRD/`)
4. Existing Angular code (`_mounts/services/falcon-web-platform-ui/`)
5. Falcon component registry (`_mounts/brain-sk/registries/FALCON_COMPONENT_REGISTRY.md` + `_mounts/brain-outputs/component-registry/components/<comp>/`)
6. HTML / React visual source (`_mounts/theme/HTML/` and `_mounts/theme/React/`)
7. Best-practice assumptions — flagged `[INFERRED]`

## How to apply
**Before ANY task touching Falcon UI / PRDs / components / pages / gaps / validation / PES:**
1. Read `C:\Falcon\falcon-wiki\00-MOCs\AI-Agent-Onboarding.md`
2. Resolve ambiguous terms via [[Glossary]]
3. Open the projection note for the entity (e.g. `20-Pages/Organization-Hierarchy.md`)
4. Read the **transcluded canonical sections** (not just the frontmatter — frontmatter is for Dataview, knowledge lives in the embedded Brain Outputs files)
5. Prefix every fact with source: `[VAULT]` / `[BRAIN-OUT]` / `[BRAIN-SK]` / `[MEMORY]` / `[CODE]` / `[WIKI]` / `[INFERRED]`
6. NEVER edit projection notes — they're auto-regenerated. To change a fact, invoke the matching Brain SK skill that writes to Brain Outputs.
