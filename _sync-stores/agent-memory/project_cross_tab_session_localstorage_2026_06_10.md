Standard shared-session model (Gmail/GitHub); explicit accepted trade-off: **per-tab multi-user is gone** (two users at once now needs a second browser profile/incognito).

**ROOT CAUSE of "always asks login in new tab":** `[CODE] apps/host-shell/src/app/core/auth/token-storage.service.ts` kept `access_token`/`refresh_token` in **sessionStorage** (per-tab) and `[CODE] apps/host-shell/falcon-facades/host-auth.facade.ts` (FALCON_AUTH for MF remotes) read the same keys. Asymmetry: `SessionProvider` already persisted `falcon_user_session`/`falcon_org_node` in **localStorage** — only the tokens were per-tab.
