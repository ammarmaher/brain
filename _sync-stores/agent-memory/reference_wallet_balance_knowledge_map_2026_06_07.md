**CHARGING CASCADE (nearest-expiring):** every balance action allocates `ContractFunded` buckets that are Active + in-window + Available>0, ordered `ExpiresAt → EffectiveFrom → BucketId` (nearest-expiry first), greedy fill, leftover → `InsufficientBalance`. Funding decision (multi-wallet): Master fully covers→Master; partial+master+comm covers→Both (needs comm priorities) else Fail(PriorityOrderRequired); comm covers→CommChannel(needs priorities); else Fail(InsufficientFunds). `[CODE] AllocateOcsMonetaryBucketsPolicy.cs`, `ResolveWalletFundingDecisionPolicy.cs`.
