**Admin-console Wallet & Balance Management is now 100% DATA-DRIVEN on comm-channels (A2 model, mirrors mgmt-console) — all static channel data removed.** Root bug the user reported: clicking **"Show All"** revealed phantom channels because `showAllChannels()` set `activeChannels` to the hardcoded `WB_CHANNELS` 5-catalog instead of the wallet's live channels.

**Backend was already correct** — `GET {systemGW}/api/commerce/accounts/{id}/hierarchy` returns VISIBLE-ONLY channels: Commerce `GetAccountHierarchyHandler.cs:73` `accountNode.CommChannels.Where(c => c.Visibility)` (only in MultipleWallets mode; SingleWallet returns no channels). The System-Gateway `AccountHierarchyMapper` drives all three lists (`channels[]`, `summary.channelWallet[]`, per-node `channelBalances[]`) from `commerceResponse.CommChannels` (left-joining Charging balances by `SameId`); Charging has NO visibility concept. So the bug was purely the admin FE re-injecting static channels.

**Fix (admin-console ONLY; mgmt untouched; backend untouched; FE-only):**
- `modules.ts`: `WbChannelId = string` (opaque real `IChannel.id`, was the 5-name union); `WbAllocation extends Record<string,number>{single}`; new `WbChannelIcon` type.
- `data/wallet-channels.ts`: deleted `WB_CHANNELS` catalog → exports cosmetic `resolveChannelGlyph(name)→{tone,icon}` (generic fallback). `data/map-wallet-data.ts`: deleted `resolveChannelId`/`buildChannelSlotMap`/`WB_CHANNEL_IDS`/`ZERO_ALLOC`; `mapChannels`→`buildWbChannels` (empty→`[]`, NO catalog fallback); `nodeToAllocation`→`allocationForNode`; masterSubBalances→`channelTotalsFrom` (all keyed by REAL channelId, unbounded N). `data/transfer-request.ts`: deleted `channelIdByWbId` reverse crosswalk → wire `channelId` is now IDENTITY (the view channel id IS the real backend id; `__ch_<realId>` holder).
- `services/wallet.service.ts`: initial `activeChannels=[]`; **`showAllChannels()` = `(api.view()?.channels ?? []).map(c=>c.id)`** (THE bug fix); `masterSubBalances: Record<string,number>`; `rateChannel` default `''`; added `channelDefs` computed; empty-multiple coercion (multiple+0 channels → effective single).
- Components: settings-card / allocation-table / drawer take a live `channelDefs` input; labels via a `channelDisplayLabel()` shim (legacy seed keys translated, live `IChannel.name` verbatim). **Allocation-table grid is now dynamic** `[style.gridTemplateColumns]="gridCols()"` (one `minmax(0,1fr)` per live channel, UNBOUNDED — replaced the capped `--falcon-wallet-cols-multi-1..5` token CSS; R3: admin emits NO leading org track since org is the split-pane left slot; single-with-transfer keeps the `transfer|1fr|transfer` 3-track + `.wb-cell-amt{grid-column:2}` placement rules). `wbm-icons` channel-icon `kind`→`WbChannelIcon` + generic `@default` arm (note: this component is dead on the admin render path — iconography is via holder-icon URLs). Removed dead `--falcon-wallet-cols-*` tokens from `libs/falcon-ui-tokens/.../wallet.tokens.css`.
