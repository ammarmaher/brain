**THE FE HOUSE RULES** (SoT = `[BRAIN-OUT] Brain Outputs/understanding/frontend/ANGULAR_AND_TAILWIND_RULES.md` + `patterns/README.md` + `patterns/FALCON_COMPONENT_CUSTOMIZATION_PATTERN.md`; also `01-CANONICAL_PATTERN.md §5`): (1) **Falcon UI Core `<falcon-*>` is the ONLY UI kit**; (2) **Tailwind v4 utilities in templates ONLY — NO SCSS / no component CSS / no PrimeNG**; (3) **no native HTML interactive primitives** (`<select>/<button>/<input>/<table>` etc. → use the `falcon-angular-*` equivalent; raw HTML = bottom rung = opens a GAP_REGISTRY entry); structural `<div>/<span>` wrappers carrying Tailwind classes + `@if/@for` are FINE; (4) **palette-over-intent tokens** `--falcon-{family}-{shade}` (Noor law) for Admin-Console-consumed code; (5) **no inline styles** except runtime-computed GEOMETRY (`[style.height.%]`, org-chart px); (6) **Falcon `@theme` tokens only, no arbitrary `text-[13px]`**.

**8-STEP CUSTOMIZATION LADDER** (`FALCON_COMPONENT_CUSTOMIZATION_PATTERN.md`): use as-is → use inputs → add ng-template/slots → add a variant → upgrade the lib component → build a NEW lib component → app-level wrapper → **raw HTML = GAP**.
