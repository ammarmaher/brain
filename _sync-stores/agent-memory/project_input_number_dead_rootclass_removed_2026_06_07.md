**What was dead & why:** `rootClass` is declared but NEVER read in `render()` on the input-number components — `[CODE] falcon-input-number-tw.tsx:52` (`@Prop() rootClass`) + the shadow twin `[CODE] falcon-input-number.tsx:55` both hardcode their wrapper `<div>` (`inline-flex …` / `falcon-input-number-wrap`) and ignore `this.rootClass`.
