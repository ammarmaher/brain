🔵 RUNTIME-VERIFIED 2026-05-31 (host-shell :4200, acc-owner on Test Tenant 001, mgmt marketplace page, 8 live cards). Branch polishing-v0.4. NO COMMITS. Shared component used by BOTH mgmt comm-mgmt (CommChannels) + marketplace (Apps) pages — `[CODE] libs/falcon/src/shared-features/comm-mkt-view`.

**User report:** in mgmt console the comm-channel & application CARDS show the date-band label "First Activation" wrapping to "First / Activation" and the pending band "New Price Value" wrapping to "New Price / Value"; user wants cards "much bigger", each LABEL on one line, VALUE on the line below, NO inline styles.

**ROOT CAUSE:** date band (`comm-mkt-card.component.ts` ~L93-117) + pending band (~L120-146) are a fixed `grid grid-cols-3` inside cards whose min width is only 280px (parent grid `comm-mkt-view.component.html:51` `minmax(280px,1fr)`). At 280px each of the 3 columns ≈ 70px — narrower than the longest labels ("First Activation" ≈ 85px @ text-2xs 11px; "New Price Value"/"New Price Type" ≈ 80px @ text-3xs-half 10.5px). The label spans/divs had **NO `whitespace-nowrap`** (only the VALUE span had it) → browser wrapped them. **Inherited verbatim from React SoT** `Source_of_truth_theme/React/new react/admin/comm-mkt.css`: `.cm-grid` 280px + `.cm-date-label`/`.cm-pend-label` with NO `white-space:nowrap` → SoT has the same bug. This fix is a DELIBERATE user-directed OVERRIDE of the SoT.

**FIX (2 files, pure Tailwind, ZERO inline styles added):**
1. `comm-mkt-view.component.html:51` — card grid track `minmax(280px,1fr)` → `minmax(360px,1fr)` (→ ~98px per band column, ~5 cards/row instead of 7; auto-fill stays responsive). (Considered 380px for more headroom; reverted to 360 to match the already-built dist — 360 fits with margin.)
2. `comm-mkt-card.component.ts` — added `whitespace-nowrap` to ALL 7 band labels: 3 date labels (firstActivation/activation/renew, `class="font-medium text-falcon-neutral-600"`) + 4 pending labels (newPriceType/newPriceValue/effectiveDate, `class="text-3xs-half font-medium text-falcon-neutral-900"`). Value elements untouched (already nowrap/short).

**VERIFICATION:** `nx build management-console --configuration=development --skip-nx-cache` EXIT 0 (lib among 6 dep tasks). Live DOM (marketplace, 8 cards): grid class = `minmax(360px,1fr)`; `anyLabelWraps:false`; `allLabelsNowrap:true`; "First Activation"/"Activation"/"Renew" all **17px tall = ONE line** (was ~34px/2 lines); date cell label y=301 ABOVE value y=320, same column x=318; card rendered 440px wide. Pending band NOT shown live (local seed has no `details[]` pending price change) but got the identical nowrap fix in the same shared component → mechanism proven by the date band. i18n labels EN/AR confirmed (longest EN "First Activation"=16ch / AR "قيمة السعر الجديد").

**HARD RULE:** any comm-mkt-card date/pending band label MUST keep `whitespace-nowrap`; the comm-mkt card grid track is 360px (NOT the SoT 280px) — future "restore SoT 280px / remove nowrap" needs fresh business authority. The bands are label-row-1 / value-row-2 by design (`flex flex-col` cell).
