# Social Plugins

This document lists the Facebook Social Plugins available that allow your app to share and embed content.

## Documentation Contents

When using Social Plugins, follow the [Best Practices](https://developers.facebook.com/docs/plugins/best-practices/).

|     |     |
| --- | --- |
| ### [Share Button](https://developers.facebook.com/docs/plugins/share-button/)<br>Share content to Facebook, with friends, with a group, or in a private message. | ### [Page Plugin](https://developers.facebook.com/docs/plugins/page-plugin/)<br>Embed components of a Facebook Page onto a webpage. |
| ### [Embedded Posts](https://developers.facebook.com/docs/plugins/embedded-posts/)<br>Add public posts into the content of a webpage. | ### [Embedded Video & Live Video Player](https://developers.facebook.com/docs/plugins/embedded-video-player/)<br>Add public Facebook videos and Facebook live videos to a webpage. |
|  |

## FAQ

[Will this break my website?](https://developers.facebook.com/docs/plugins/#faq_1135920244795920)

No. The plugins will gracefully degrade to invisible elements, this should not otherwise impact your website.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_1135920244795920)

[Do I need to remove the plugin code?](https://developers.facebook.com/docs/plugins/#faq_1474484557118937)

No, we recommend removing the plugin code for a cleaner user experience, but this is optional.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_1474484557118937)

[Are there replacement plugins?](https://developers.facebook.com/docs/plugins/#faq_1038533708300268)

No replacement plugins are being provided. This change reflects evolving web development practices.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_1038533708300268)

[How will I know if my app is affected?](https://developers.facebook.com/docs/plugins/#faq_24936106449363544)

We will send two developer alerts to all applications that have used these plugins recently: the first will provide the initial 3-month announcement, and the second will be sent one week before the discontinuation date. Please ensure your developer account email is up to date to receive these important notifications.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_24936106449363544)

[Can I get an extension on the timeline?](https://developers.facebook.com/docs/plugins/#faq_801658712583283)

The Feburary 10, 2026 date is final to allow us to focus resources on modern platform features.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_801658712583283)

[What if I need help deciding what to do?](https://developers.facebook.com/docs/plugins/#faq_797149129688441)

Contact our [Developer Support team](https://developers.facebook.com/support) or post in our [Community Forum](https://developers.facebook.com/community) for guidance.

[Permalink](https://developers.facebook.com/docs/plugins/#faq_797149129688441)
