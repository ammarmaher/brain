# Learn about the Fundraiser API

The Fundraiser API allows a nonprofit’s external fundraising website to be shared on Facebook and Instagram to extend the effectiveness, reach and visibility of their campaigns. Campaigns on the fundraising website can be mirrored on Facebook allowing people to raise money on their Facebook fundraiser, while keeping donation information in sync between the mirrored campaigns.

\[How it works\] Tech providers can integrate with the Fundraiser API on behalf of their nonprofit clients, or nonprofits can integrate directly.
