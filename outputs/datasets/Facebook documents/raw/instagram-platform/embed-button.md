# Embed Button

You can get a public Instagram photo, video, Reel, or Guide post’s embed HTML code and use it to embed the post in other websites. Embedded posts automatically resize to fit their container, so they will look great on both desktop and mobile websites.

![](https://scontent-lax7-1.xx.fbcdn.net/v/t39.2365-6/89824380_234684177669792_3559805517834485760_n.png?_nc_cat=105&ccb=1-7&_nc_sid=e280be&_nc_ohc=glznioVQMcQQ7kNvwES3nZs&_nc_oc=AdrYCkso1ZqMuwADZpdTR82mIr-D9O6lKq8HJwSrPTbYfjA-q37PWYvjpLkhsy-2G7M&_nc_zt=14&_nc_ht=scontent-lax7-1.xx&_nc_gid=NxknE9GnniF-rRX7TKCANQ&_nc_ss=7b289&oh=00_Af5bL_w6_0hJf5d9-M7VK6WJEL1a5uXjv_JRizHliTVdIg&oe=6A25833F)

People own their Instagram content, so each embedded post gives proper attribution by displaying the post owner’s username and linking to the post owner’s profile.

To get a post’s embed HTML code using its **Embed** button, view the post in a desktop or mobile web browser, click the **\[...\]** menu...

![](https://scontent-lax3-1.xx.fbcdn.net/v/t39.2365-6/89738865_133859414730000_8450155087510110208_n.png?_nc_cat=102&ccb=1-7&_nc_sid=e280be&_nc_ohc=EwUzPeQ9hQ8Q7kNvwHbN0HY&_nc_oc=AdqZMilXXOEycXonmuSoqrS9nr3qjBXyJZrBLARUJ9WK9HctJYXCHHjcoo31JL550wo&_nc_zt=14&_nc_ht=scontent-lax3-1.xx&_nc_gid=NxknE9GnniF-rRX7TKCANQ&_nc_ss=7b289&oh=00_Af6PWNMCcTIBQWCLAgh-Z9SiuNucBT-Bq7_L7cbH1CrooA&oe=6A258FA7)

... then click the **Embed** button:

![](https://scontent-lax3-1.xx.fbcdn.net/v/t39.2365-6/89722283_616218892556786_5027045768683323392_n.png?_nc_cat=109&ccb=1-7&_nc_sid=e280be&_nc_ohc=7ga04yr5Uu4Q7kNvwHPlN2m&_nc_oc=AdqtaT1HkcljOUjLIeM0Ppdg2ziWVEZVLSya7p84Wj7y-wNCSpG-ueIOvBY_kulesmU&_nc_zt=14&_nc_ht=scontent-lax3-1.xx&_nc_gid=NxknE9GnniF-rRX7TKCANQ&_nc_ss=7b289&oh=00_Af5Aes1R_dRbskIqg6IsS-DSMg2fNqpuQBnbwBcGnxDmtw&oe=6A2592DC)

This will reveal the post’s embed HTML code, which you can copy and paste in the website where you want the post to appear.

![](https://scontent-lax7-1.xx.fbcdn.net/v/t39.2365-6/89731764_695269624611829_7513410501070553088_n.png?_nc_cat=101&ccb=1-7&_nc_sid=e280be&_nc_ohc=8y8-Rd5DAq0Q7kNvwESd9m6&_nc_oc=AdoeVW6CaBaJl4xuBkf0s-g513q0Jau_iLIe0DT803SCXtQfpb1yPj9BCKsC8E9mR7M&_nc_zt=14&_nc_ht=scontent-lax7-1.xx&_nc_gid=NxknE9GnniF-rRX7TKCANQ&_nc_ss=7b289&oh=00_Af4GcGUf9mPK6Ftplqx634lJMx1qUU3_BOQVSsHygLnsJw&oe=6A25811E)

By default the post will include its caption, but you can omit the caption by unchecking the **Include caption** checkbox.
