# iOS

Audience Network supports the following ad formats for iOS:

- [Banner and Medium Rectangle](https://developers.facebook.com/docs/audience-network/guides/ad-formats/banner/ios)
- [Interstitial](https://developers.facebook.com/docs/audience-network/guides/ad-formats/interstitial/ios)
- [Native](https://developers.facebook.com/docs/audience-network/guides/ad-formats/native/ios) and take a look at Audience Network's [Native Ads Template](https://developers.facebook.com/docs/audience-network/guides/ad-formats/native/ios-template)
- [Native Banner](https://developers.facebook.com/docs/audience-network/guides/ad-formats/native-banner/ios)
- [Rewarded Video](https://developers.facebook.com/docs/audience-network/guides/ad-formats/rewarded-video/ios)
- [Rewarded Interstitial](https://developers.facebook.com/docs/audience-network/setting-up/ad-setup/ios/rewarded-interstitial)

Relevant code samples written in Swift and Objective C are available on [our GitHub sample app repository](https://l.facebook.com/l.php?u=https%3A%2F%2Fgithub.com%2Ffbsamples%2Faudience-network%2Ftree%2Fmaster%2Fsamples%2Fios&h=AUB0ooC0NWKUtdU8_0erlQHPA1SvV7a-yR8Bu7DGBr8C1dzxC8aA3K3E1ZyUJw6wHx0XdP5ySDzqq38Bi1Pc-8-teIOXYxthudm4WWkqFS8XefaU3FYuHbW5hxhDCQps0oYgNjIbBNROVQ)
