# Implementation Testing

Test your Meta Audience Network SDK implementation to verify the experience before pushing it to production. Audience Network offers both platform testing and client testing methods.

In this section:

## Testing

- [On the Platform](https://developers.facebook.com/docs/audience-network/setting-up/testing/platform) \- add a Test Device and Test Users
- [On a Test Device](https://developers.facebook.com/docs/audience-network/setting-up/test/test-device)
- [Validate Ad Requests](https://developers.facebook.com/docs/audience-network/setting-up/test/validate-ad-requests)
- [Integration Checklist](https://developers.facebook.com/docs/audience-network/setting-up/test/checklist-errors)
- [Override-enable Test Mode](https://developers.facebook.com/docs/audience-network/setting-up/testing/enable-test-mode) \- use this option to see a test ad

## Debugging and Troubleshooting

- [Onboarding Debugger](https://developers.facebook.com/tools/property/checklist) \- verfy your bidding integration. Have your Property ID handy.
- [Publisher Bid Token Debugger](https://developers.facebook.com/tools/biddertoken/debugger/) \- verify the tokens that are sent in bid requests, to make sure that the fields are correctly populated to get a bid response.
- [Error Codes](https://developers.facebook.com/docs/audience-network/setting-up/test/checklist-errors#errors) \- of Production Ad Requests
