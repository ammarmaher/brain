# Admost (Closed Beta)

This topic explains how to set up the Admost bidding mediation partner for Audience Network.

## Before You Start

- **Audience Network SDK requirements:** 6.2.1 or later ( [Android](https://developers.facebook.com/docs/audience-network/guides/adding-sdk/android) \| [iOS](https://developers.facebook.com/docs/audience-network/guides/adding-sdk/ios))
- **Admost SDK requirements:**
  - iOS: 1.4.7.8
  - Android: 2.2.8
- **Supported formats:** Banner, Interstitial, Medium Rectangle, Native, Native Banner, Rewarded video.

## How to Set Up Bidding

Sign up to Admost [here](https://l.facebook.com/l.php?u=https%3A%2F%2Fresources.admost.com%2Fsign-up%2F&h=AUAp_ates1pmxzfmnvouPG4bVIwJ4VO4QopMWG2ELhFG07vtSKFO5M6OmAHv90NBeTpd7OfrK0GrLbLonWNSfUoG_TklK5pKBrd3Asw2ooxlvZ7rweXkOPKWeM3THx1DFKxaHuoFg3Rm0A) or email **info@admost.com** to start using adMost Mediation.

You will receive all the [integration steps](https://l.facebook.com/l.php?u=https%3A%2F%2Fadmost.github.io%2F&h=AUBuWbU0im6EKx1X9BZGFvxapFTuXkAHSbeLKvTGg9VXpPlsHTV-n-uMvkZ4Bk5qOLloOWju4QAwk0Mlj-Ky-Z-JkQN8-LzcyUWjB3lBRrUJiOwPS1uA8OLdRc3-B91GchAZRuJVc7lV3Q) and documentation with the guidance of your dedicated account manager. You’ll get 24/7 technical support through all the processes.

You can contact your Admost account manager for bidding, and setup will be done by the Admost team.

## Features and Tips

- You can make several A/B tests via Admost’s A/B Test tool by making changes in ad/impression intervals, frequency capping as well as country specific changes and different waterfall and bidding setups.

- You can check all setup and see test ads from bidding via Admost Test Suite by adding your devices as testers.

- You can always see and compare all bidding partner performances through Admost Analytics.
