# Audience Network Setup

To get started with Audience Network, you will need the following:

- A link to your app on the App Store or Google Play Store

- A two-factor authentication method

- The payout bank account routing number and account number; or the ability to sign in to the bank account


01. Go to [Monetization Manager](https://business.facebook.com/pub/moma). The first time you integrate with Audience Network, you'll be given the option to choose your Business Manager account (if you already have one), or create a new one. Note: If you create a new one, you'll need a personal Facebook account to log in to Business Manager to confirm your identity.

03. App details. Enter the Play Store or App Store link and the app name. Click Next.

     ![](https://lookaside.fbsbx.com/elementpath/media/?media_id=855812876879092&version=1778515253)

05. Ad setup. Select the ad format for your ad placement. Click Next.

     ![](https://lookaside.fbsbx.com/elementpath/media/?media_id=1146093529149075&version=1778512002)

07. Two-factor authentication. Monetization Manager requires setting up two-factor authentication (2FA) in order to keep your payout account secure. This



09. Payout account. Before adding a payout account, you need to set up a finance admin, because one is not assigned by default to business accounts.

    1. Click All tools and click Settings. On some pages, All tools will be collapsed to a menu button displayed as three horizontal lines in the upper left corner of the page.
    2. Click the three dots beside the user that you want to make the finance admin, and then click Edit business portfolio permissions. Note that this user will need to be the one to set up the payouts account in Monetization Manager.
    3. Click View advanced options, and then select Manageunder the Finance settings.
    4. The Finance admin should then log in, click All tools and select Monetization Manager.
    5. Click Payouts, click Securely add payout account and then continue through the Payout account setup following the prompts.
10. Verification. We'll review your app, which can take up to 72 hours. Note that you can complete the remaining steps now, and your app will start monetizing once we've approved.

12. SDK integration.



     We recommend that you always run the latest SDK version.



     After each of bullet points below, click on the ![](https://lookaside.fbsbx.com/elementpath/media/?media_id=2824847561105216&version=1778512002)icon to copy the ID for use when integrating with your mediation partner.


    - Click on Add system user access token, then click the Generate token button. Copy the token, and save it for later use.

    - Copy the Property ID, and save it for later use.

    - Click on Add placement ID, then copy the Placement ID, and save it for later use.
