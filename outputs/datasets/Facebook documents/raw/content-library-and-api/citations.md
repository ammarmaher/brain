# Citations

Each release of each product has a registered Digital Object Identifier (DOI) included in the citation formats we provide on this page. It is important that you cite the product(s) and Meta when using our data.

## Meta Content Library API version v6.0

### Citation format

Meta Platforms, Inc., (Month Accessed, Year Accessed). Meta Content Library API version v6.0 [https://doi.org/10.48680/meta.metacontentlibraryapi.6.0](https://l.facebook.com/l.php?u=https%3A%2F%2Fdoi.org%2F10.48680%2Fmeta.metacontentlibraryapi.6.0&h=AUAvS9Qoxkty9FisOreDVnZi5-xRXO2eJeXRd6pvyQGHPl_rO3MDKfnh7LujXbNn9bfve084nOJZJPFjVqAFapnxpFh7B37VK9QwebtsGEcPoMk3u5-dwHeQob2x31_ZAWQt7Ziv1ZOU5g)

### Abstract

**Meta Content Library API** is an API for querying and analyzing the Meta public content archive, supporting data analysis in Python and R in Meta Secure Research Environment.

### Keywords

Meta, Facebook, Instagram, social media, Facebook Pages, Facebook groups, Facebook events, Facebook posts, Facebook profiles, Facebook comments, Instagram accounts, Instagram posts, Instagram comments, Instagram creator accounts, Instagram business accounts, Instagram personal accounts, reels, stories

Meta Platforms, Inc., (Month Accessed, Year Accessed). Meta Content Library version v6.0 [https://doi.org/10.48680/meta.metacontentlibrary.6.0](https://l.facebook.com/l.php?u=https%3A%2F%2Fdoi.org%2F10.48680%2Fmeta.metacontentlibrary.6.0&h=AUD3xZNAMf9ia19SqM_MZv7edvj3hYytYTH3vRAO4akgG2G-ghd3xHz-aq4bWxLrjo4g2GKVsUZs4d6rsL9vxdlRg1yvtq03oSb_jtYCgkr-XQNKrp0f8diUZPsA1_IXl0avWephjueYOw)
