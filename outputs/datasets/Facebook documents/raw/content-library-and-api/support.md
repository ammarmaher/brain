# Support

For product support and troubleshooting, you can raise a ticket to the Meta Support Community to triage and help with your questions.

See [Get help](https://developers.facebook.com/docs/content-library-and-api/support/get-help) to learn how to access and use this tool.

But first:

- For answers to many common questions, see [Frequently asked questions](https://developers.facebook.com/docs/content-library-and-api/support/faqs).

- For questions related to the application for access and eligibility requirements, see [Get access](https://developers.facebook.com/docs/content-library-and-api/get-access).


## Data Transparency Status Page

For information about ongoing issues, please visit the [Data Transparency Status page](https://l.facebook.com/l.php?u=https%3A%2F%2Fmetastatus.com%2Fdata-transparency&h=AUB3LrHCOy_MCOM2Qs5y4Dy7dcY5k_wofAi2jy_xEpneFmWgd6Im6tTrk9gXtFARsOb7r1XAkMBGXNP8hgMzSyNdc5BtNYcvqnL6Tu98aZfF8NGI5pvbm4ZaYMWEF_P2JW3GP9i9GS2k1A). There you can check if there are any disruptions or outages affecting Meta Content Library, Content Library API or Secure Research Environment. We recommend subscribing through the RSS feed button on the status page for updates.
