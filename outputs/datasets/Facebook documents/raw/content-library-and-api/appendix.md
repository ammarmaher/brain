# Appendix

The following reference materials are available to further enhance your use of the Meta Content Library and API in your work.

## Documentation Contents

|     |     |
| --- | --- |
| ### [Data dictionary](https://developers.facebook.com/docs/content-library-api/data)<br>Provides detailed information on the data fields available in the public content accessed by Meta Content Library and API. | ### [Field expansion](https://developers.facebook.com/docs/content-library-api/field-expansion)<br>Explains the concept of _field expansion_ which is available for some fields on certain nodes. |
| ### [Search quality approach](https://developers.facebook.com/docs/content-library-api/search-quality)<br>Reviews the set of measures Meta uses for monitoring search quality and presentation of any known limitations to search functionality and performance. | ### [Get API code](https://developers.facebook.com/docs/content-library-api/get-api-code)<br>Explains how to get an automatically generated code snippet for your Meta Content Library search that you can use in the Meta Content Library API. |
| ### [Share producer lists](https://developers.facebook.com/docs/content-library-and-api/appendix/share-producer-list)<br>Explains how to share producer lists between Meta Content Library and Content Library API. | ### [Share API search ID](https://developers.facebook.com/docs/content-library-and-api/appendix/api-search-id)<br>Explains how to create and use an API search ID in Meta Content Library that acts as an alias for a search including all its filter settings. |
