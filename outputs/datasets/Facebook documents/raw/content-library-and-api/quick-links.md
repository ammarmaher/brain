# Quick links

Quick access to topics of interest to users of both Meta Content Library and Meta Content Library API:

### [Frequently asked questions](https://developers.facebook.com/docs/content-library-api/disclosures)

Answers to common questions about Content Library and API.

### [Get help](https://developers.facebook.com/docs/content-library-api/get-help)

How to contact us for help with Content Library and API questions and issues.

### [Get access](https://developers.facebook.com/docs/content-library-api/get-access)

How to get access to Content Library and API.

### [Advanced search](https://developers.facebook.com/docs/content-library-api/adv-search)

Advanced search options including Boolean operators, using multiple operators, and grouping.

### [Citations](https://developers.facebook.com/docs/content-library-api/citations)

Guidelines for citing Content Library tools and datasets in your publications.

### [Rate limiting and query budgeting](https://developers.facebook.com/docs/content-library-api/rate-limiting)

Rate limits and query budget that apply to each product and to each researcher.

### [Search quality approach](https://developers.facebook.com/docs/content-library-api/search-quality)

Detailed information about how search works in Content Library and API, including caveats and known issues.

### [Data dictionary](https://developers.facebook.com/docs/content-library-api/data)

Description of the data names displayed in the Content Library web UI and the corresponding API fields returned in Content Library API search responses.

### [Get API code](https://developers.facebook.com/docs/content-library-api/get-api-code)

Instructions for using the Get API code tool to capture search parameters in Content Library as Python or R code that can be used in Content Library API.

### [Share API search ID](https://developers.facebook.com/docs/content-library-and-api/appendix/api-search-id)

Instructions for using the Get API search ID tool to capture search parameters in Content Library as an alias for the search that can be used in Content Library API or shared with others.
