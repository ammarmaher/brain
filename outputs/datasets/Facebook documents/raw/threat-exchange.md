# ThreatExchange

ThreatExchange is a free signal sharing and threat intelligence platform for industry and non-profit organizations working to prevent harm. Meta created ThreatExchange so that participating organizations can share threat data using a convenient, structured, and easy-to-use platform that provides privacy controls to enable sharing with only desired groups. You can [apply for membership](https://developers.facebook.com/products/threat-exchange) today!
