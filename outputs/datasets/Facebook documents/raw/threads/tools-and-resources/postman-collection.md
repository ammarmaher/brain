# Threads API Postman Collection

[Postman](https://l.facebook.com/l.php?u=https%3A%2F%2Fwww.postman.com%2F&h=AUCuktvdAH_K1zh2hk9VDJModX6kHkLMcNYGv--XlIgkc8UhjO6rfTMvkfOVI18B0fgbTLw7pEkSRIU6pfQ0AxWJ3sZbs8lsfhiXdaGKCDffQMRZvR-7OYdljc4nK5CaYpN8vGXfsC6AVQ) is a popular tool to help test and develop APIs. To make it more convenient for developers integrating with Threads API, we've created a Postman collection that contains a full set of API calls.

This document shows you how to set up the Threads API Postman Collection and use Postman to make requests to Threads API.

## Threads API Collection

Our collection for Threads API has been migrated to Postman! You can find our new collection on Postman at [https://www.postman.com/meta/threads/overview](https://l.facebook.com/l.php?u=https%3A%2F%2Fwww.postman.com%2Fmeta%2Fthreads%2Foverview&h=AUClWnaQKIyYKdMhIgLuxp1vi1_i5ICwIhTsqsQrwlhXOkABCp4zKOKw7Zsd8g2aWfFl_J9WxnE7UM7-5LbUlS5vJk2NJdPb4t0QrblLHZTCy9LADg-50OKPmGdPMAmkrsjbjAro_g3knw).

You can view our Postman documentation for the following functionalities:

- Authorization
- Post to Threads
- Read and Manage Threads
- Discover Threads
- Display Threads
- Troubleshooting

Instructions on how to set up the collection and use it to make requests are available in the [Get Started](https://l.facebook.com/l.php?u=https%3A%2F%2Fwww.postman.com%2Fmeta%2Fthreads%2Fcollection%2Fdht3nzz%2Fthreads-api&h=AUBD1SKjv-qmn9oFDc5LZqeKqXZEu59Kwp82--VgBAq3aQM4pQMGcrW0N1lafEDgRFNAkdfsBRgtiBgWq9s2pDgzgix8vIelV9ScAaJYLq1KoY4psiDA6uaplijvfM4gCzFbiwd656Kjrg) section.

We will update the Postman collection over time. Please note that all of the latest features may not be showcased in the Postman collection. Please refer to the developer documentation changelog for the most up-to-date features: [Threads Changelog](https://developers.facebook.com/docs/threads/changelog).
