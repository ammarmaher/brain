# Cover Photo

## Reading

The cover photo for a Facebook [Event](https://developers.facebook.com/docs/graph-api/reference/event), [Group](https://developers.facebook.com/docs/graph-api/reference/group), or [Page](https://developers.facebook.com/docs/graph-api/reference/page).

### New Page Experience

This endpoint is supported for [New Page Experience](https://developers.facebook.com/docs/pages/new-pages-experience/).

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `id`<br>numeric string | The ID of the cover photo<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `cover_id`<br>id | Deprecated. Please use the `id` field instead<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `offset_x`<br>float | When greater than 0% but less than 100%, the cover photo overflows horizontally. The value represents the horizontal manual offset (the amount the user dragged the photo horizontally to show the part of interest) as a percentage of the offset necessary to make the photo fit the space.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `offset_y`<br>float | When greater than 0% but less than 100%, the cover photo overflows vertically. The value represents the vertical manual offset (the amount the user dragged the photo vertically to show the part of interest) as a percentage of the offset necessary to make the photo fit the space.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `source`<br>string | Direct URL for the person's cover photo image<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
