### Fields

| Field | Description |
| --- | --- |
| `id`<br>numeric string | The video copyright ID<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `content_category`<br>enum | The content category of the reference file.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `copyright_content_id`<br>numeric string | The copyright content ID<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `creator`<br>[User](https://developers.facebook.com/docs/graph-api/reference/user/) | The account that created the copyright<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `excluded_ownership_segments`<br>list<VideoCopyrightSegment> | The list of audio and video segments excluded from copyright monitoring. This includes both self-defined excluded segments as well as system generated excluded segments. |
| `in_conflict`<br>bool | Whether the video copyright is in active conflict with another rights owner's video copyright.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `monitoring_status`<br>enum | Whether the video is monitored successfully for copyright. The status could be NOT\_EXAMINED, COPYRIGHTED, and ERROR.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `monitoring_type`<br>enum | Whether the video is monitored for VIDEO, AUDIO, or VIDEO\_AND\_AUDIO<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `ownership_countries`<br>VideoCopyrightGeoGate | Two string arrays of [ISO 3166 format country codes](https://l.facebook.com/l.php?u=http%3A%2F%2Fwww.iso.org%2Fiso%2Fcountry_codes%2Fiso_3166_code_lists%2Fcountry_names_and_code_elements.htm&h=AUDiQph4Od4KxR_J8YT5ooy5_iqz_c3IbFtD1-4v0Fhx1UuDNzGzcxq5iJJnMA7Iu55haWZUJkF_YpE7Aywg9xTPLRRhHH07QvdnhKf_PYBibbHOZbXm5ta_Om1OekZ2JFWKbb-hqYEc-A). `included_countries` are where the owner owns the rights to the content. `excluded_countries` are where the owner does not own the rights to the content. When both lists are empty, rights ownership is worldwide.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `reference_file`<br>CopyrightReferenceContainer | The reference file<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `reference_file_disabled`<br>bool | Whether the reference file is disabled.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `reference_file_disabled_by_ops`<br>bool | Whether the reference file has been disabled by ops.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `reference_owner_id`<br>string | The ID of the reference video owner<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `rule_ids`<br>[list<VideoCopyrightRule>](https://developers.facebook.com/docs/graph-api/reference/video-copyright-rule/) | A list of matching rules applied to the copyrighted content<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `tags`<br>list<string> | The tags/keywords associated with the copyright |
| `whitelisted_ids`<br>list<numeric string> | A list of page IDs or user IDs, who are allowed to use the copyrighted content.<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |

## Creating

You can make a POST request to `video_copyrights` edge from the following paths:

- [`/{page_id}/video_copyrights`](https://developers.facebook.com/docs/graph-api/reference/page/video_copyrights/)

When posting to this edge, a [VideoCopyright](https://developers.facebook.com/docs/graph-api/reference/video-copyright/) will be created.

### Parameters

| Parameter | Description |
| --- | --- |
| `attribution_id`<br>numeric string or integer | For Rights Manager Lite, please provide ID of the Page where the attribution should link to. Provide 0 if you want to unlink the reference file with its current attribution. For Rights Manager Pro, please provide ID of the attribution to be displayed for valid monitored videos matching this content. |
| `content_category`<br>enum {episode, movie, web} | A string array representing the reference file's content category |
| `copyright_content_id`<br>numeric string or integer | This is the ID of the content which needs to be copyrighted. It could be an ID of a video, or an ID of a live video.<br>Required |
| `excluded_ownership_countries`<br>list<UTF-8 encoded string> | A string array of [ISO 3166 format country codes](https://l.facebook.com/l.php?u=http%3A%2F%2Fwww.iso.org%2Fiso%2Fcountry_codes%2Fiso_3166_code_lists%2Fcountry_names_and_code_elements.htm&h=AUCTNsk0_NfDShXQXuAbkaY_F3ouLlY75carRjDkRxSii24TvNiPEqMVvErJ3BdjMAsZ0G-dugcFco0lZnR2lQr3YEcdTL4QWtq-YyUE5b5qIz8ETv0fxO4FTZe2kw2ZhFENAm0I5imwaQ), where the owner does not own the rights to the content |
| `excluded_ownership_segments`<br>list<Video Match Segment> | An array of match segments to exclude from the matching algorithm |
| `start_time_in_sec`<br>float | Required |
| `media_type`<br>enum {VIDEO\_AND\_AUDIO, VIDEO\_ONLY, AUDIO\_ONLY} | Required |
| `duration_in_sec`<br>float | Required |
| `segment_source`<br>enum {PUBLISHER\_DEFINED, PAUSE\_LIVE\_MONITORING, LABEL\_MUTED, PUBLISHER\_MUTED, MUSIC\_RESTRICTION\_MUTED\_STILL\_VIDEO, MUSIC\_RESTRICTION\_MUTED\_MULTI\_TRACK, AUDIO\_LIBRARY\_USAGE, MELODY, INELIGIBLE\_CONTENT} | Default value: `PUBLISHER_DEFINED` |
| `is_reference_disabled`<br>boolean | If true, stop creating matches for the reference file. |
| `is_reference_video`<br>boolean | Default value: `false`<br>True indicates that the content is used only as a reference video, and is not available for consumption on Facebook. |
| `monitoring_type`<br>enum {VIDEO\_AND\_AUDIO, VIDEO\_ONLY, AUDIO\_ONLY} | Setting to indicate whether the content has copyright ownership on video, audio, or both. |
| `ownership_countries`<br>list<UTF-8 encoded string> | A string array of [ISO 3166 format country codes](https://l.facebook.com/l.php?u=http%3A%2F%2Fwww.iso.org%2Fiso%2Fcountry_codes%2Fiso_3166_code_lists%2Fcountry_names_and_code_elements.htm&h=AUDnZ8lfz1hvBSkMDIxTg0Pa60k3owVlIe1zHrpqQW5NkiKdfzVuqqpHiZqlDV93dWuK-DTpDgHxjxn_3rQIy6Kz2WgqVlNW34FBbuI0T27sum8T2jBaFPkndVqFxgArNwv06nYXzzfuEg), where the owner owns the rights of the content |
| `rule_id`<br>numeric string or integer | A copyright rule to be applied to the copyrighted content. |
| `tags`<br>array<string> | The tags/keywords associated with the copyright |
| `whitelisted_ids`<br>list<numeric string> | A list of page IDs or user IDs, who are allowed to use the copyrighted content. |
| `whitelisted_ig_user_ids`<br>list<numeric string> | A list of instagram user IDs who are allowed to use the copyrighted content. |
