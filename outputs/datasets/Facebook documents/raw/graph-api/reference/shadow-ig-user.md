## Creating

You can make a POST request to `media` edge from the following paths:

- [`/{ig_user_id}/media`](https://developers.facebook.com/docs/graph-api/reference/shadow-ig-user/media/)

When posting to this edge, an [IGUser](https://developers.facebook.com/docs/graph-api/reference/shadow-ig-user/) will be created.

### Parameters

| Parameter | Description |
| --- | --- |
| `alt_text`<br>string | Accessibility of a media |
| `audio_configuration`<br>string | audio\_configuration |
| `branded_content_sponsor_ids`<br>array<int64> | A JSON array of IG user IDs to tag as branded content sponsors on the media. |
| `caption`<br>string | Default value: `""`<br>Caption for the media to be created |
| `collaborators`<br>array<string> | Field that adds collaborators to a media |
| `image_url`<br>string | A URL where the image to be uploaded |
| `is_carousel_item`<br>boolean | is\_carousel\_item |
| `is_paid_partnership`<br>boolean | Boolean flag indicating whether the post is a paid partnership. When set to true, the post will display a 'Paid partnership' label. Can be used with or without specific sponsor IDs. |
| `location_id`<br>numeric string | Location id tagged in media |
| `media_type`<br>string | Default value: `"IMAGE"`<br>media\_type |
| `product_tags`<br>array<JSON object> | IG Shopping products tagged in media |
| `share_to_feed`<br>boolean | share\_to\_feed |
| `thumb_offset`<br>string | A numberic string for thumbnail offset in video stream to generate thumbmail |
| `user_tags`<br>array<JSON object> | IG users tagged in media |
| `username`<br>string | username<br>Required |
| `x`<br>float | x |
| `y`<br>float | y |
