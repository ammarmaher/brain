# Canvas

## Reading

A canvas document

### Parameters

This endpoint doesn't have any parameters.

| Field | Description |
| --- | --- |
| `id`<br>numeric string | ID of the canvas |
| `background_color`<br>string | Background color of the canvas |
| `body_elements`<br>list<CanvasPhoto\|CanvasHeader\|CanvasVideo\|CanvasText\|CanvasCarousel\|CanvasButton\|CanvasFooter\|CanvasStoreLocator\|CanvasProductList\|CanvasProductSet> | Body element nodes for the canvas |
| `business_id`<br>numeric string | The business id for the canvas product set element |
| `canvas_link`<br>string | The canvas link for the canvas |
| `collection_hero_image`<br>[Photo](https://developers.facebook.com/docs/graph-api/reference/photo/) | First element as photo inside canvas to use as hero media for canvas collection |
| `collection_thumbnails`<br>list<CanvasCollectionThumbnail> | Canvas elements that can be used as thumbnails for canvas collections |
| `element_payload`<br>string | Payload that contains all element |
| `elements`<br>list<RichMediaElement> | Body element nodes for the canvas |
| `fb_body_elements`<br>list<CanvasPhoto\|CanvasHeader\|CanvasVideo\|CanvasText\|CanvasCarousel\|CanvasButton\|CanvasFooter\|CanvasStoreLocator\|CanvasProductList\|CanvasProductSet\|CanvasDynamicProductSet\|CanvasTemplateVideo\|CanvasDynamicPhoto> | Body element nodes for the canvas, used by FB internal apps and includes elements who's API is not public yet |
| `is_hidden`<br>bool | The canvas is hidden or not |
| `is_published`<br>bool | Publish status of the canvas |
| `last_editor`<br>[User](https://developers.facebook.com/docs/graph-api/reference/user/) | User who last edited this canvas |
| `linked_documents`<br>[list<Canvas>](https://developers.facebook.com/docs/graph-api/reference/canvas/) | The canvas documents that are reachable via buttons/links in this document |
| `name`<br>string | Name used to label the canvas<br>[Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `owner`<br>[Page](https://developers.facebook.com/docs/graph-api/reference/page/) | Page that owns this canvas |
| `property_list`<br>list<string> | List of properties for this canvas |
| `store_url`<br>string | The associated app store URL for the canvas |
| `style_list`<br>list<enum> | Canvas level style attributes |
| `tags`<br>list<string> | Tags associated with Canvas |
| `ui_property_list`<br>list<string> | List of UI properties to set when viewing this canvas from creation tools |
| `unused_body_elements`<br>list<CanvasPhoto\|CanvasHeader\|CanvasVideo\|CanvasText\|CanvasCarousel\|CanvasButton\|CanvasFooter\|CanvasStoreLocator\|CanvasProductList\|CanvasProductSet> | Body element nodes that belong to the canvas but are not used |
| `update_time`<br>int32 | Last updated time of the canvas |
| `use_retailer_item_ids`<br>bool | HACK: Flag for whether or not the ad creative that uses this Canvas should use retailer\_item\_ids or not |

## Creating

You can make a POST request to `canvases` edge from the following paths:

- [`/{page_id}/canvases`](https://developers.facebook.com/docs/graph-api/reference/page/canvases/)

When posting to this edge, a [Canvas](https://developers.facebook.com/docs/graph-api/reference/canvas/) will be created.

### Parameters

| Parameter | Description |
| --- | --- |
| `background_color`<br>string | Default value: `FFFFFFFF`<br>Background color of the canvas |
| `body_element_ids`<br>list<numeric string or integer> | A list of all canvas element ids inside this canvas |
| `enable_swipe_to_open`<br>boolean | Default value: `false`<br>Field used to mark if swipe to open is enabled |
| `hero_asset_facebook_post_id`<br>numeric string or integer | hero\_asset\_facebook\_post\_id |
| `hero_asset_instagram_media_id`<br>numeric string or integer | hero\_asset\_instagram\_media\_id |
| `is_hidden`<br>boolean | Field used to mark if the canvas is visible or not |
| `is_published`<br>boolean | Default value: `false`<br>Field used to mark the publish state of the canvas |
| `name`<br>string | Default value: `Untitled Canvas`<br>Field used to label docs by the editor tool |
| `source_template_id`<br>numeric string or integer | ID of EntRichMediaDocumentTemplate that the Canvas document is created from |

### Return Type

This endpoint supports [read-after-write](https://developers.facebook.com/docs/graph-api/overview/#read-after-write) and will read the node represented by `id` in the return type.

Struct {

`id`: numeric string,

}

## Updating

You can update a [Canvas](https://developers.facebook.com/docs/graph-api/reference/canvas/) by making a POST request to [`/{canvas_id}`](https://developers.facebook.com/docs/graph-api/reference/canvas/).

### Parameters

| Parameter | Description |
| --- | --- |
| `background_color`<br>string | Background color of the canvas |
| `body_element_ids`<br>list<numeric string or integer> | A list of canvas element ids |
| `enable_swipe_to_open`<br>boolean | Field used to mark if swipe to open is enabled |
| `hero_asset_facebook_post_id`<br>numeric string or integer | hero\_asset\_facebook\_post\_id |
| `hero_asset_instagram_media_id`<br>numeric string or integer | hero\_asset\_instagram\_media\_id |
| `is_hidden`<br>boolean | Field used to hide a (published) canvas |
| `is_published`<br>boolean | Field used to mark the publish state of the canvas |
| `name`<br>string | Field used to label the canvas |
| `source_template_id`<br>numeric string or integer | ID of EntRichMediaDocumentTemplate that the Canvas document is created from |

### Return Type

This endpoint supports [read-after-write](https://developers.facebook.com/docs/graph-api/overview/#read-after-write) and will read the node to which you POSTed.

Struct {

`success`: bool,

}

| Error | Description |
| --- | --- |
| 100 | Invalid parameter |
