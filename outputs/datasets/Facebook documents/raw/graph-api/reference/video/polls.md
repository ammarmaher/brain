# Video Polls

## Reading

Polls attached to this video

### Example

HTTPPHP SDKJavaScript SDKAndroid SDKiOS SDK [Graph API Explorer](https://developers.facebook.com/tools/explorer/?method=GET&path=%7Bvideo-id%7D%2Fpolls&version=v25.0)

```
GET /v25.0/{video-id}/polls HTTP/1.1
Host: graph.facebook.com
```


### Parameters

This endpoint doesn't have any parameters.

### Fields

Reading from this edge will return a JSON formatted result:

```
{
    "data": []
}
```

#### `data`

A list of [VideoPoll](https://developers.facebook.com/docs/graph-api/reference/video-poll/) nodes.

### Error Codes

| Error | Description |
| --- | --- |
| 210 | User not visible |

## Creating

You can make a POST request to `polls` edge from the following paths:

- [`/{video_id}/polls`](https://developers.facebook.com/docs/graph-api/reference/video/polls/)

When posting to this edge, a [Video](https://developers.facebook.com/docs/graph-api/reference/video/) will be created.

### Parameters

| Parameter | Description |
| --- | --- |
| `correct_option`<br>int64 | Number of the correct option (in order, starting from 1) |
| `options`<br>array<string> | Text options for users to select in order<br>Required |
| `question`<br>string | Question text<br>Required |
| `show_results`<br>boolean | True to show the results after voting, otherwise false |

### Return Type

This endpoint supports [read-after-write](https://developers.facebook.com/docs/graph-api/overview/#read-after-write) and will read the node represented by `id` in the return type.

Struct {

`id`: numeric string,

`option_ids`: List \[\
\
numeric string\
\
\],

}

| Error | Description |
| --- | --- |
| 100 | Invalid parameter |

You can't perform this operation on this endpoint.
