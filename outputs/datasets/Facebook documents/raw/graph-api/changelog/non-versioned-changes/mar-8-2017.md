# March 8, 2017

## Marketing API, Budget Limits Enforcement

Starting from Wednesday, March 8th, 2017, we start enforcing a budget validation to prevent creation and editing of ads with lifetime budgets exceeding 1 million USD. Reach-Frequency assets are exempt from this limit and validation.
There is no change to the daily budget limit, and it was already enforced at 1 million USD.

When a life budget for an Ad exceeds this cap, you see an error: `ErrorCode::ADPRO2__CAMPAIGN_BUDGET_TOO_HIGH (1885261)`.
