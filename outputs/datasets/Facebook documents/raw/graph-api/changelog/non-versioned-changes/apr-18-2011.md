# April 18, 2011

## Removing `year` and `status` properties of `affiliations` column in `user` FQL table

These properties will be removed from the `affiliations` column. You should use the `education` property of the [User object](https://developers.facebook.com/docs/reference/api/) in the Graph API or the `education_history` column of the user FQL table instead.
