# September 12, 2013

## Local currency payments

We are migrating all canvas app developers that use the legacy Facebook Credits payments system to local currency payments. Facebook Credits will no longer be supported on September 12, 2013 and you must migrate to [local currency](https://developers.facebook.com/docs/concepts/payments/) payments to continue to accept payments from users.
