# February 3, 2022

Out-of-cycle changes.

## Marketing API

### Reach and Frequency

#### Objectives being deprecated

Starting March 3, 2022, you will no longer be able to create app installs, offsite conversions, or conversion-based billing for video view campaigns for new predictions. The existing predictions/campaigns with these settings cannot have their end dates extended beyond June 15, 2022 for video view conversion billing and September 22, 2022 for app install and offsite conversion campaigns.

The following reach and frequency objectives will be deprecated:

- Mobile app installs: `APP_INSTALLS` as objective
- Offsite conversions: `OFFSITE_CONVERSIONS` as objective
- Video view conversion-based billing (CPA): `VIDEO_VIEWS` as objective with `is_conversion_goal` set to `true`

This change will affect the following endpoints:

- [`POST /{rf-prediction-id}`](https://developers.facebook.com/docs/graph-api/changelog/non-versioned-changes/(/docs/marketing-api/reference/reach-frequency-prediction))
- [`POST /{ad-account-id}/reachfrequencypredictions`](https://developers.facebook.com/docs/marketing-api/reference/reach-frequency-prediction)

#### Deprecation timeline

##### Beginning March 3, 2022

- The `objective` parameter will no longer accept the values `APP_INSTALLS`, `OFFSITE_CONVERSIONS`, or `VIDEO_VIEWS` (as specified above) _unless_ the `rf_prediction_id_to_share` parameter is set to a valid prediction ID.
- The `is_conversion_goal` parameter will no longer accept the value `true` _unless_ the `rf_prediction_id_to_share` parameter is set to a valid prediction ID.
- When the `is_conversion_goal` parameter is set to `true`, the `end_time` and `stop_time` parameters cannot be set to any value greater than or equal to the Unix timestamp `1655251200` (June 15, 2022 at midnight UTC).
- When the `objective` parameter is set to `APP_INSTALLS` or `OFFSITE_CONVERSIONS`, the `end_time` and `stop_time` parameters cannot be set to any value greater than or equal to the Unix timestamp `1663830000` (September 22, 2022 at midnight UTC).

##### Beginning June 15, 2022

The delivery of all reach and frequency buying type video view campaigns with conversion-based billing will be stopped at this point. Any residual campaigns of this type continuing to run after this date will be disabled.

##### Beginning September 22, 2022

The delivery of all reach and frequency buying type app install and offsite conversion campaigns will be stopped at this point. Any residual campaigns of this type continuing to run after this date will be disabled.
