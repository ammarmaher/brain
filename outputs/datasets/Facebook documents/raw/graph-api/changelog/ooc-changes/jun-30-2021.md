## Instagram Basic Display API

#### Private Account Access Tokens

_Applies to all versions._

[Long-lived access tokens](https://developers.facebook.com/docs/instagram-basic-display-api/guides/long-lived-access-tokens) for private Instagram accounts can now be [refreshed](https://developers.facebook.com/docs/instagram-basic-display-api/guides/long-lived-access-tokens#refresh-a-long-lived-token). In addition, [permissions](https://developers.facebook.com/docs/instagram-basic-display-api/overview#permissions) granted to apps by app users with private accounts are now valid for 90 days.
