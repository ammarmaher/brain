# Meta App Event Tracking

Meta App Events allows your app or web page to track events, such as a person installing your app or completing a purchase.

For information on tracking App Events for Business Messaging, please see the [**App Events API for Business Messaging**](https://developers.facebook.com/docs/messenger-platform/analytics/messaging-events-api) in our [Messenger Platform documentation](https://developers.facebook.com/docs/messenger-platform).

## Common Uses

- [Track events in Android apps](https://developers.facebook.com/docs/app-events/getting-started-app-events-android)
- [Track events in iOS apps](https://developers.facebook.com/docs/app-events/getting-started-app-events-ios)
- [Track events using Codeless App Events](https://developers.facebook.com/docs/app-events/codeless-app-events)
