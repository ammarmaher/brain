## 9. Methodology

5 parallel agents (`general-purpose` subagent type) each given a self-contained brief with: required-read file list · structured output template (6 fixed headings) · source-prefix rule · word cap. Each agent read 12-18 source files and returned ~2500-3500 words of structured findings. The orchestrator consolidated into:
- REPORT.html (interactive deliverable)
- CONSOLIDATED-REGISTRY.md (this file)
- 5 raw agent findings preserved at `agent-findings/`
- 5 priority new E-* entity stubs at `Brain SK/_obsidian/40-API/`
- BR-X cross-module rule registry at `Brain Outputs/datasets/cross-module-business-rules/`

## 10. Hand-back contract

When the product team answers the 105 yes/no questions in `REPORT.html` and exports the JSON, a follow-up session can:
1. Promote the answered OPEN BR rules from `[OPEN]` to `[CONFIRMED]` in the PRD files
2. Author the new V-rules + E-* entities whose binding rule is now CONFIRMED
3. Write the per-flow trace files (Send-Transaction etc.) using the canonical Add-Client.trace pattern
4. Author the cross-module BR-X-* rules into the new registry
5. Update GAP-BIZ-* status from `open` to `closed` (with the answer recorded in the gap file)
