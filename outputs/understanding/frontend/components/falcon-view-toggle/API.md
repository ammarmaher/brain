## CVA / ngModel / Reactive Forms

`[CODE]` **NO ControlValueAccessor.** The component does NOT implement `ControlValueAccessor` and does NOT register `NG_VALUE_ACCESSOR`. It cannot be driven by `formControlName` / `[(ngModel)]`. Binding is exclusively via the `[(value)]` two-way model (or `[value]`+`(valueChange)`). This is correct for a **view-state switcher** (not a submitted form value) but is a constraint to document (GAP G4).

## Signal compatibility

No `@Input`/`@Output` decorators, no NgModule, no lifecycle hooks, no subscriptions → nothing to tear down. This is a textbook Angular 21 signals component.

## Accessibility
